          Execute a jump

          Sends a jump command for the player's figure. Only allowed when in the LANDED state.

          Authorizations:
          ApiKeyAuth
          Request Body schema: application/json
          required
          strength
          required
          number <float> [ 0 .. 20 ]

          The magnitude of the jump. Translates directly to velocity when multiplied with the normalized direction vector.

          required
          object or Vector2 (object)

          Angle in degrees (0 is straight up, clockwise) as {"angle_deg": <value>}, or a direction vector. If a vector is provided, it will be normalized before being multiplied by strength.

          Responses

          Local Development Server (HTTPS)

          https://localhost:8443/api/v1/bot/jump

          Relative path (useful for production)

          https://217.160.132.56/api/v1/bot/jump

            }
          }

            Change server-wide game mode

            Administrator only. Updates the active game mode configuration for the server. All three dimensions can be changed independently. Omitted fields retain their current value. fixed_stage_id is required when stage_type is Fixed. goal_height is used when session_type is Race or Timetrial and stage_type is Generated.

            Authorizations:
            BearerAuth
            Request Body schema: application/json
            required
            fall_mode
            string
            Enum: "Checkpoint" "Hardcore"

            Checkpoint: bots respawn at the last reached checkpoint on fall. Hardcore: bots are eliminated on fall.

            session_type
            string
            Enum: "Race" "Timetrial" "Infinite"

            Race: first to goal height wins. Timetrial: each bot races alone for best time. Infinite: no goal, climb as high as possible.

            stage_type
            string
            Enum: "Generated" "Fixed"

            Generated: platforms are procedurally generated each session. Fixed: a predefined stage layout is used.

            fixed_stage_id
            string

            Identifier of the fixed stage to load. Required when stage_type is Fixed; ignored otherwise.

            goal_height
            number <float>

            Target height (in world units) that bots must reach to finish. Used for Race and Timetrial on Generated stages; ignored for Fixed stages.

            Responses

            Local Development Server (HTTPS)

            https://localhost:8443/api/v1/admin/mode

            Relative path (useful for production)

            https://217.160.132.56/api/v1/admin/mode

                WebSocket game state stream

                Upgrades the connection to a WebSocket for real-time streaming of the game world. The stream provides updates on player positions and newly generated platforms.

                Message Format (JSON):

                {
  "type": "position_update" | "platform_spawn",
  "timestamp": "ISO-8601 string",
  "data": { ... }
}
                • For position_update: data contains player_id, x, y, vx, vy, and state.
                • For platform_spawn: data contains platform_id and rect.

                Responses

                Local Development Server (HTTPS)

                https://localhost:8443/api/v1/system/stream

                Relative path (useful for production)

                https://217.160.132.56/api/v1/system/stream
